# Offline replay (#11)

No model and no network. Synthetic fixtures generated by `gen_fixtures.py` (Python, TypeScript, Rust, SQL, UTF-8, and the note/multimodal cases from issues #1, #6, #7, #8).

```sh
python3 benchmarks/replay/gen_fixtures.py   # regenerates fixtures (deterministic)
python3 benchmarks/replay/replay.py         # writes results/offline-replay.json; exits 1 if the candidate fails any oracle
```

Arms: `none` (no budget), `historical` (character-based preview, note dropped on spill) and `candidate` (the `cbg` core). The oracles use the fixture's ground truth, not the core. The `historical` arm is a documented emulation of the behavior described in the issues, not the private runtime. This replay does not measure tokens or cost and does not support any savings claim on real tasks.
