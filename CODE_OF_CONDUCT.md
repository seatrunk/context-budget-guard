# Code of conduct

Help people contribute without making them endure harassment. Critique the work, explain disagreements, and respect different experience levels. Assume a mistake can be corrected; do not assume consent to share someone's private information.

Harassment, discriminatory abuse, threats, sexualized attention, doxxing, and repeated disruptive behavior are not acceptable. This applies in issues, pull requests, reviews, and project-related community spaces.

Report conduct concerns privately to the repository maintainer through a private contact channel. If none is available, request one without publishing names or sensitive details. Use the [security policy](SECURITY.md) for vulnerability reports, not public issue threads. Do not publish evidence that exposes another person's private information.

Maintainers may edit or remove content, warn participants, restrict participation, or ban accounts according to severity and repetition. They should explain the decision privately when safe, protect reporter confidentiality as far as practical, and recuse themselves when personally involved. A participant may request reconsideration with new context; there is no separate appeals panel or promised response deadline.
